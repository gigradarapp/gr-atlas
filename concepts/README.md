# Buzo Atlas — Design Concepts

Four standalone website directions, each adapted from a MotionSites design reference for the Buzo Atlas thesis. They are visual explorations, not product claims or production-ready screens.

| Direction                                       | Starting reference                                                  | Atlas focus                                            |
| ----------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------ |
| [Real-Time Alerts](real-time-alerts/index.html) | [Real-Time Alerts](https://motionsites.ai/?prompt=real-time-alerts) | Evidence-linked operator exception desk                |
| [Neuralyn](neuralyn/index.html)                 | [Neuralyn](https://motionsites.ai/?prompt=neuralyn-hero)            | Editorial portfolio-intelligence narrative             |
| [AI Runtime](ai-runtime/index.html)             | [AI Runtime](https://motionsites.ai/?prompt=ai-runtime)             | Agentic command centre for learn, coordinate, allocate |
| [Agent Grove](agent-grove/index.html)           | [Agent Grove](https://motionsites.ai/?prompt=agent-grove)           | Cinematic agent-forward product landing page           |

All four preserve the current positioning: **Buzo Atlas is the operating system for an AI-native family-office model focused on the nightlife and culture economy.** They deliberately use fictional data and make no claim that Buzo Atlas is a regulated family office, investment adviser, or operator of third-party capital.
